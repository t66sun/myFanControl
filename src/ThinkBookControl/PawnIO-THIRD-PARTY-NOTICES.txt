ThinkBookControl optionally embeds and loads the existing signed PawnIO LpcIO module for read-only EC telemetry on the validated Lenovo 21CX / HYCN42WW profile.

ThinkBookControl does not install or update the PawnIO driver, does not request elevation, and accesses only the measured EC report window. The driver must already exist and the process must already be elevated.
Reported RPM values are firmware EC reports; independent physical RPM measurement and arbitrary fan-speed control are not verified.
