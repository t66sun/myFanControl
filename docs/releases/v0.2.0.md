# myFanControl v0.2.0

本地交付版本，2026-10-07。GitHub 最新已发布版本仍为 v0.1.3。

- CPU/GPU 独立温度数字托盘图标，窗口显示时保持可见；悬停查看精确读数，失效显示 `--`。
- 每扇风扇分别设置升温/降温滞回与升速/降速延时。范围均为 0～10 的整数，默认依次为 0°C、2°C、0 秒、0 秒。
- 以每扇上次成功改变转速时的温度为基准，先达到滞回阈值，再连续计时；条件中断重置，成功调速更新基准。另一扇变化不影响本扇基准。
- 首次应用立即设置目标；90°C 高温保护和温度失效恢复绕过等待。保留每秒最多降速 300 RPM 及原驱动保护。
- 曲线圆圈为启用目标，方块为已应用目标；草稿不同显示点线启用曲线。实际测速继续独立显示。
- 旧共享延时迁移到两扇独立配置。编辑/保存不应用控制；预设和复制仍只包含曲线节点。

验证：51 项合成控制策略检查及离线 WPF UI 检查通过，包含配置迁移、无效输入、保存/重载、托盘生命周期、模拟电源通知和 100%/150%/200% 缩放截图。证据位于 `artifacts/diagnostics/v0.2.0-final/`；未执行本版真机控制或实际睡眠验收。

交付：两个 Windows x64 ZIP、基于自包含 ZIP 的安装程序和覆盖三件交付物的 `SHA256SUMS.txt`，位于 `release/v0.2.0/`。仍需已安装 PawnIO 2.2，安装程序未签名。仅适用原已验证机型，不扩展 GPU 控制或其他硬件。
