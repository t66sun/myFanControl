# v0.2.1

安装向导自动准备 PawnIO：已有正式签名的 2.2 或更高版本时跳过；缺少或较旧时，从官方固定的 2.2.0 发布下载，验证固定 SHA256 和 Windows Authenticode，再调用官方静默安装。无法确认现有驱动或校验失败时停止并显示错误。官方安装器要求重启时，向导提示重启；完成后再启动应用。

首次缺驱动安装需要联网。卸载应用保留共享驱动与个人配置。应用安装器仍未签名；官方 PawnIO 安装器与正式驱动的签名独立验证。两个便携 ZIP 仍要求用户预装 PawnIO。

包含 v0.2.0 的 CPU/GPU 数字温度托盘、每把风扇独立的温度滞回和升降速延时、曲线目标标记。参数语义见 [v0.2.0](v0.2.0.md)。

按用户要求，仅进行离线接口、控制策略、UI、构建和包内容检查；不执行安装器、真实安装或睡眠测试。
