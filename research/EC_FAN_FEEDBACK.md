# HYEC42WW 风扇反馈与控制候选

本记录以官方 BIOS 包的静态候选 EC 区为依据。后续实机已取得与该算法一致的两路主机侧 EC 反馈；**物理校准、通道与 CPU/GPU 对应关系及控制写入仍未验证**。镜像提取依据见 [EC_FIRMWARE_FINDINGS.md](EC_FIRMWARE_FINDINGS.md)。

## 反馈路径

候选 bank-0 的 0xC46E / 0xC4A8 分别读取 XDATA 181F/181E 和 1821/1820，组合非零计数，调用 0xCB45；结果低 16 位按高字节在前写入 8800/8801 或 8802/8803。零计数时写零；后续限制结果不超过 0x1D4C（7500）。这些行为与双通道风扇转速反馈相符，但通道与物理风扇对应关系尚未确认。

0xCB45 构造除数和常数 0x20E6DA（2156250），进入 common-bank 的算术助手。主代理用受限离线 8051 解释器执行候选例程，逐指令处理实际镜像字节，与独立整数公式比较：

```
raw == 0 ? 0 : min((2156250 // raw) & 0xFFFF, 7500)
```

1022 个双通道用例通过，覆盖零值、255/256/257、287/288/289 的限幅边界、65535 及固定种子的随机 16 位输入。解释器仅支持本路径所需指令，未实现完整处理器、银行、计时或真实设备；遇到未知指令、未初始化 XDATA 或超出范围的控制流会停止。该检查证明候选代码的离线数值行为，不证明运行时会执行、实际时钟或数值单位。

证据：[Verify-ThinkBookEcTach.py](../scripts/Verify-ThinkBookEcTach.py)、[ec-tach-offline-verification.json](ec-tach-offline-verification.json)、[ec-fan-feedback-disassembly.txt](ec-fan-feedback-disassembly.txt)。

## 输出调节路径

| EC 内部 XDATA 候选 | 静态行为 |
| --- | --- |
| 8800/8801、8802/8803 | 两通道计算后的反馈值，高字节在前 |
| 8804、8805 | 单字节目标；比较助手将目标乘 100，并应用约 ±100 的区间 |
| 880C、880D | 非零时覆盖上述目标；小于 15 时目标清零，大于 75 时限为 75，其他值复制 |
| 880E、880F | 非零时直接影响 1804/1805 输出，最大值限制为 127 |
| 1804、1805 | 输出寄存器候选；根据反馈与目标逐步加减，或使用覆盖值 |

例如 0xC517 起读取目标和反馈，通过 0xCBA5/0xCBF0 计算目标×100的下/上界；低于范围时增加 1804，高于范围时减少。不能据此把内部寄存器暴露为可用设置接口，也不认定清零覆盖字段就一定完成产品要求的恢复。

## 传输仍待确认

- ACPI 的 ERAM 映射 FE0B0300，字段与候选 XDATA 83xx 有一致性线索；这不足以证明所有 XDATA 88xx 都能按偏移直接映射到主机 FE0B08xx。尚未读取该主机地址。
- SMA2 的 0x80 处理包含地址高字节和数量限制，不能直接用 RDER(0x8800) 访问这些候选值。
- 已安装 AcpiVpc.sys 中未找到 RDER/WTER 等方法名的 ASCII 或 UTF-16 字符串；这不是完整动态行为证明。
- 新克隆官方 PawnIO.Modules，提交 52a7e536dff3e53c96917a28caac5e0fa6510696。IsaBridgeEC 源码的发现逻辑仅列出部分桌面 SuperIO 型号，不能当作本机通用 EC MMIO 后端；其发现操作也包含配置端口写入。LpcACPIEC 仅提供 62/66 端口访问，不提供这里需要的任意 MMIO 读取。没有运行这些模块。

下一步核对主机 SRAM 映射、受支持的读取传输、实际 EC 版本与银行路径，再以只读遥测确认单位和通道。控制与曲线开发继续依赖这些验证。

## 主机侧反馈实测新增证据（2026-10-01）

固定 4E/4F 间接读取中，主机侧 0800–0803 取得两路高字节在前的反馈，0804/0805 目标与反馈量级一致。20 轮基线反馈为 4303/4329、目标 43；安静模式的连续保持段目标 34→31，反馈逐渐下降。完整 60 轮采样跨过三次长暂停，不能整体当作连续的模式响应曲线。

主机侧 8800–880F 的双读全部不一致，不能直接把固件 XDATA 数值当作主机地址。这里只使用实际验证的 0800–0805 窗口，不推导完整 SRAM 别名或写入能力。产品标注“EC 报告 RPM”，不把零值或软件反馈等同于独立物理仪器校准。

原始和独立核对见 [EC_FEEDBACK_DIAGNOSTIC.md](EC_FEEDBACK_DIAGNOSTIC.md)。新发现的候选设置/清除命令见 [EC_PMC2_CANDIDATE.md](EC_PMC2_CANDIDATE.md)，尚未执行该路径的硬件命令。
