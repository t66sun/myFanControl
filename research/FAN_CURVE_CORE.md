# 自动风扇曲线计算内核

代码：[FanControlPolicy.cs](../src/FanControl.Core/FanControlPolicy.cs)。这是无硬件访问的计算组件，未接入监控程序或风扇写入。目标仍是实机 RPM 控制与曲线，计算检查不能替代硬件验收。

## 已实现

- 曲线温度严格递增、RPM 不递减，点值必须在传入范围内；最高温度点请求该范围的最大值。
- 分段线性插值，曲线端点外限幅；拒绝 NaN、无穷和不合理温度输入。
- 使用所有必需传感器的最高温度；缺失、空值、无效值、陈旧或未来时间戳均输出恢复固件自动控制的请求。
- 降温迟滞与降速速率限制；升温不受降速限幅影响；高温最大值请求不被普通写入间隔延迟。
- 不重复请求已确认的 RPM；不足 1 RPM 的降速步长保持原请求状态。
- 无可变执行状态。AppliedControl 必须由调用方在硬件设置成功后提供；提出设置请求不等于设置成功。

## 主代理验证

Release 构建零警告、零错误。27 项计算与失效流程检查通过，包括插值、配置拒绝、CPU/GPU 最高温度、降温迟滞、时间限制、高温分支、坏样本恢复请求、无效历史拒绝和亚 RPM 步长。

运行方式：

```powershell
& .\.tools\dotnet\dotnet.exe run --project tests/ControlPolicyVerification -c Release
```

测试中的 1500–7500 RPM、温度阈值和时间参数是合成输入，不是已启用的 21CX 硬件配置。每个实际配置仍需通过本机协议、允许范围、温度来源和恢复路径验证。
